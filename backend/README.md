# Kidney Tumor AI - Backend

This directory contains the backend services and machine learning inference code for the Kidney Tumor Detection AI project. It encompasses both a REST API (built with FastAPI) and a standalone interactive web interface (built with Streamlit). 

The backend relies on PyTorch and pre-trained U-Net architectures for segmenting multi-modal T1-Weighted MRI and Contrast CT scans to accurately localize and measure renal tumors.

## Project Structure

- `api.py`: FastAPI server that provides a RESTful `/analyze` endpoint for the Next.js frontend to interact with.
- `app.py`: Standalone Streamlit application providing a visual interface for uploading scans and viewing results directly.
- `requirements.txt`: Python package dependencies.
- `Dockerfile`: Production-ready Docker container configuration.
- `models/`: Directory containing the pre-trained PyTorch model weights (`kidney_ct_scan.pth` and `kidney_mri.pth`).

## Local Development Setup

We recommend using Python 3.11 for compatibility.

1. **Create and activate a virtual environment:**
   ```bash
   python -m venv venv
   source venv/bin/activate
   ```

2. **Install dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

## Running the Services

### 1. FastAPI Server (For Next.js Frontend)
To start the REST API server locally (which powers the main Next.js frontend application):
```bash
uvicorn api:app --reload --host 0.0.0.0 --port 8000
```
*Note: The FastAPI instance is defined in `api.py`, not `app.py`.*

### 2. Streamlit Dashboard (Standalone)
To run the Streamlit application (an alternative, standalone dashboard):
```bash
streamlit run app.py
```

## Docker

If you prefer using Docker, the backend can be built and run using `docker-compose` from the project's root directory:
```bash
docker-compose up -d --build backend api
```
- The Streamlit app will be available at `http://localhost:8501`.
- The FastAPI server will be available at `http://localhost:8000`.

## API Documentation

When the FastAPI server is running, interactive API documentation is automatically generated by Swagger UI. You can view the endpoint specifications and test the `/analyze` route directly from your browser by navigating to:
`http://localhost:8000/docs`
